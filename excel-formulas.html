Excel Formula Library

Learn formulas step by step with sample data, ready-to-copy formulas, and examples from accounts payable, vendor reconciliation, GST, bank reconciliation and reporting.

Showing all formulas

BASICS

1. SUM — Add amounts

Adds numbers across a selected range.

=SUM(B2:B6)
Example: If B2:B6 contains ₹1,000, ₹500, ₹250, ₹750 and ₹100, the result is ₹2,600.
BASICS

2. AVERAGE — Average value

Calculates the arithmetic average of numbers.

=AVERAGE(B2:B6)
Example: Values 10, 20 and 30 return 20.
BASICS

3. COUNT — Count numeric cells

=COUNT(B2:B100)
Counts how many cells in the range contain numbers. Useful for checking numeric invoice totals.
BASICS

4. COUNTA — Count filled cells

=COUNTA(A2:A100)
Counts non-empty cells, such as invoice numbers entered in column A.
LOGICAL

5. IF — Return a result based on a condition

=IF(D2=0,"Paid","Pending")
If the outstanding amount in D2 is zero, Excel shows Paid; otherwise it shows Pending.
LOGICAL

6. IFERROR — Handle formula errors

=IFERROR(A2/B2,0)
Returns the division result; if the formula produces an error (for example, division by zero), it displays 0. Choose an error message where zero could be misleading.
LOGICAL

7. AND — Check multiple conditions

=IF(AND(B2="Approved",C2<=D2),"Process","Review")
Processes a line only when approval is Approved and billed quantity in C2 does not exceed received quantity in D2. Adapt checks to your policy.
ACCOUNTING

8. SUMIF — Total for one condition

=SUMIF(A2:A100,"ABC Traders",D2:D100)
If column A contains vendor names and column D contains invoice amounts, totals the amounts for ABC Traders.
ACCOUNTING

9. SUMIFS — Total with multiple conditions

=SUMIFS(D2:D100,A2:A100,"ABC Traders",B2:B100,"Approved")
Adds column D amounts where vendor in A is ABC Traders and status in B is Approved. SUMIFS uses sum range first.
ACCOUNTING

10. COUNTIF — Count matching items

=COUNTIF(E2:E100,"Overdue")
Counts rows marked Overdue in column E.
ACCOUNTING

11. COUNTIFS — Count with multiple conditions

=COUNTIFS(B2:B100,"ABC Traders",E2:E100,"Overdue")
Counts overdue invoices belonging to ABC Traders.
LOOKUP

12. XLOOKUP — Find a matching value

=XLOOKUP(A2,VendorMaster!A:A,VendorMaster!B:B,"Not found")
Looks up vendor code in A2 in VendorMaster column A and returns the corresponding vendor name from column B. Available in newer Excel versions; not in Excel 2016/2019.
LOOKUP

13. VLOOKUP — Find data in a table

=VLOOKUP(A2,$H$2:$J$100,2,FALSE)
Searches for A2 in the first column of H2:J100 and returns the second column's value. FALSE requests an exact match.
LOOKUP

14. INDEX + MATCH — Flexible lookup

=INDEX(C2:C100,MATCH(F2,A2:A100,0))
Finds the value in F2 within A2:A100 and returns the corresponding value from C2:C100.
TEXT & DATES

15. TRIM — Remove extra spaces

=TRIM(A2)
Cleans extra spaces in copied vendor names. It helps with matching text, but does not remove every kind of non-printing character.
TEXT & DATES

16. TEXT — Display a value in a chosen format

=TEXT(A2,"mmm-yyyy")
If A2 contains a valid Excel date, returns text such as Oct-2026. Use actual dates for calculations whenever possible.
TEXT & DATES

17. TODAY — Current date

=TODAY()-A2
Calculates the number of days from the date in A2 to today, useful as a simple age-in-days calculation. Check blank and future dates separately.
ACCOUNTING

18. ROUND — Round a calculated amount

=ROUND(B2*C2,2)
Multiplies B2 by C2 and rounds the result to two decimal places. Apply the rounding approach required by your accounting policy.
ACCOUNTING

19. SUBTOTAL — Total filtered data

=SUBTOTAL(9,D2:D100)
Adds visible values in D2:D100 after filtering. Function number 9 means SUM; use 109 if manually hidden rows should also be excluded.
ACCOUNTING

20. Simple receivable ageing bucket

=IF(TODAY()-C2<=30,"0-30 Days",IF(TODAY()-C2<=60,"31-60 Days","60+ Days"))
If C2 is the invoice date, categorises age into 0–30, 31–60 or over 60 days. This simple example assumes dates are valid and not in the future; adapt for due-date ageing and unpaid invoices.
Practice tip: Copy a formula into Excel and change the cell references to match your own sheet. Formulas use commas as separators in these examples; some regional Excel settings use semicolons.
