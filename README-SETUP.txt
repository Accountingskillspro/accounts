ACCOUNTPRO SKILLS — GITHUB PAGES READY FILES

1. Upload the CONTENTS of this folder to a GitHub repository named accountpro-skills.
2. Keep index.html at the repository root.
3. Upload assets/ and articles/ folders too; do not upload only index.html.
4. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Wait a few minutes for the published link shown in Settings > Pages.

Before public launch: replace the contact email placeholder in contact.html and rewrite privacy-policy.html to accurately reflect any tools, analytics, cookies or ads used. Educational GST information must be checked against current official guidance.

This package is a static HTML website, not a WordPress theme. Publishing requires you to sign in to your GitHub account; do not share your password or OTP.
