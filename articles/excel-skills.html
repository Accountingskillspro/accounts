EXCEL FOR ACCOUNTS

5 Excel Skills Every Accountant Should Know

Excel is useful for summarising transaction data, preparing reports and supporting reconciliations. Start with these everyday tools.

1. SUM and SUMIF/SUMIFS

Calculate totals and summarise amounts by vendor, month, ledger or expense category.

2. Lookup functions

Use XLOOKUP or VLOOKUP to match invoice numbers, vendor codes and other reference fields. Check for duplicates and formatting differences.

3. IF and IFERROR

Create simple checks and handle formulas that cannot find a valid result.

4. PivotTables

Summarise large lists by month, supplier, account or cost centre. Refresh the PivotTable after updating source data.

5. Conditional formatting

Highlight duplicate invoices, overdue items and mismatches that need investigation.

Good practice: Keep an unchanged copy of source data, check formula logic and verify totals before sharing reports.
